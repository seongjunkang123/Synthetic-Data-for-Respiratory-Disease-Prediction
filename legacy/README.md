# Earlier repository files

These are the previously published CSVs and model artefacts from commit 1b52f7a.
They are preserved as historical outputs. The current 6,000-profile release,
source matrix, portable code and audited evaluation are in ../zenodo_release/.
The original “bronchi” filename refers to bronchiectasis. The generator is a
conditional WGAN-GP; CTGAN is now included only as a separate benchmark method.
